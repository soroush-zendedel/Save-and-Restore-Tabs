# Privacy Notice

**Last updated: September 30, 2026**

Save and Restore Tabs does not collect, store, transmit, sell, or share personal data or browsing data.

## Data handled on your device

- When you choose **Save open tab links**, the extension reads tab URLs from the current Firefox window and creates a text file download on your device. Only HTTP and HTTPS URLs are included.
- When you select a text file on the restore page, its lines are read locally. Valid HTTP and HTTPS URLs are opened as tabs in the current Firefox window.
- The extension does not retain a copy of the selected file or exported URLs after the operation.

The extension makes no network requests and uses no analytics, advertising, cookies, remote code, or third-party services. Files created by the browser are subject to your Firefox download settings.

## Permissions

The `tabs` permission is used to read tab URLs for the user-requested export and to create tabs for the user-requested restore. The extension does not request access to website contents or browsing history.

## Changes and contact

Changes to this notice will be reflected in this file and the repository history. For privacy questions, open an issue in the project's GitHub repository.
