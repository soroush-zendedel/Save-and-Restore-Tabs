# Contributing

Thanks for considering a contribution. Please keep changes focused, explain the user impact, and update the documentation when behavior changes.

## Development

This is a dependency-free Firefox WebExtension. Load `manifest.json` temporarily from `about:debugging#/runtime/this-firefox` to try a change. Exercise both export and restore flows in Firefox before submitting a pull request.

## Pull requests

- Describe the problem and the change.
- Include clear reproduction steps for bug fixes.
- Keep permissions minimal and explain any proposed permission change.
- Do not add telemetry, remote code, or network communication without first discussing the proposal in an issue.
- Do not include generated archives, credentials, or personal browsing data.

By submitting a contribution, you agree that it may be distributed under this project's MIT License.
